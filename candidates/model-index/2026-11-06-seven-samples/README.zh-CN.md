# 七题解题模型索引审核草稿

本目录与题库正文分离，不修改 review/bank 的原签名字节。实际审核页通过现有 QuestionBankReadSurface.readModel 展示本目录的只读投影，不将索引写进重点解析或秒杀技巧。

## 七题映射

1. 论证方式：论证形式 / 论证结构同构 / 关系同构项 / 科学主张。具体谬误为诉诸无知。
2. 逻辑填空：语境词义 / 语境对应选词、搭配与语用筛选 / 最恰当词语。文明形成题材没有准确候选代码，留空。
3. 无人机：数列规律 / 模型待映射 / 个数或人数。实际解法为三角数求层数与等差通项，现有字典没有准确模型代码，不套奇偶分组；无人机题材留空。
4. 图形分类：实际解法为包含与交叠位置关系分类，已查看原图。现有字典缺准确考点、模型、分类目标及题材代码，四维留空并写出判定依据，不套位置变换或叠加运算。
5. 真假推理：真假数量约束。命题逻辑/真假推理考点、逻辑必真结论及考试成绩预测题材缺准确代码，留空，不套论证形式考点。
6. 流水行船：相对速度与路程 / 总时间 / 水流。考点留空；time.total 和 water-flow 是旧候选中的既有词条引用，当前没有原字典全文定义，仍需复核。
7. 用水量比较：缺图2和全国平均值材料，四维均未核验，不能根据原答案或原解析反推完整材料。保留阻断说明。

## 格式与审批边界

- batch.json、dictionary.json、records.jsonl 复用项目现有本地草稿包结构，不新增正式字典条目。14个不同词条都来自 evidence/source-dictionary.draft.json，标签未改；定义字段引用原候选的适用、排除和证据要求，均标为 pending。
- records.jsonl 恰好7题，逐题 questionId/revisionDigest 与原发行及既有研究候选一致。每题最多8个维度代码，四维无法映射时保留空数组。
- 全部7条 reviewStatus 为 pending；缺材料题另在依据和待复核原因标明阻断，AI记录仍为 blocked。原生索引协议没有 blocked 状态，不擅自扩展它。
- practiceEligible 必须保留原签名题目的值，才符合现有原生包验证。它不是本轮审核通过标志，也不代表缺材料题可训练。本云审核没有模型筛选、关联或保存HTTP接口。
- 这是候选映射的本地审核接线，不是用户已批准、完整题库批量导入、生产环境关联或平台验收。没有调用原生关联工具，也没有发放增强权益。
- 原生格式仅按现有 Rust 验证逻辑核对并做 Node 行为校验；本环境缺 Rust/Tauri 完整编译条件，不能声称原生导入已实测通过。
